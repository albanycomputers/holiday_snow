# Holiday Snow
**A fun javascript Holiday season snow fall effect.**

### Requirements:

- Backdrop CMS 1.x
- PHP 8+ (While the code may technically function with PHP 7.4 at this time, we strictly require PHP 8.0+ and will not address issues related to older PHP versions.)

## Installation:

Install this module using the official Backdrop CMS instructions at https://docs.backdropcms.org/documentation/extend-with-modules

Enable the module.

## Configuration

Go to **Configuration > user Interface > Holiday Snow** (`/admin/config/user-interface/holiday-snow`).
